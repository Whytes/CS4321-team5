# MVC Architecture

This step should be done as a group.

Model-View-Controller (MVC) is an architectural pattern. A computer system’s architecture is the global organization of the software. The project requires an MVC architecture. You will use the User Stories for this learning activity; however, this is not for developing code for your project. The goal is to learn about MVC first, and then see how it applies to your project. You’ll start developing code in the next section.

Use AI with the following prompts. You don’t have to limit yourself to these, feel free to ask AI additional questions.

Goal: Learn what an MVC Architecture is

Prompt:

Explain MVC simply and include a diagram. Describe Model, View, Controller responsibilities, provide a Java example, and list common mistakes.

Prompt:

Show a simple example of MVC using JavaFX for a desktop GUI application.

Prompt:

How do you make sure a user story's implementation adheres to MVC?

Prompt:

What is separation of concerns in software development?

As you go through these prompts, you will probably need to ask AI to explain various things in more detail.
