# GitHub

This step should be done as a group. However, for best results, each individual should do this and then meet as a group and do it over discussing as you go so that you increase your understanding.

GitHub is an online platform used by developers to store, share, and collaborate on code. Each team member will create an account on GitHub. One team member will create a repository (repo) where your team’s code is stored. The person who creates the team repo will add the other members of the team as collaborators. Each individual will clone your team’s repo, work on your personal device, and then push your code back to the repo.

Understanding how GitHub works and the workflow necessary to work as a team is critical for the success of your project. This section only deals with using GitHub itself. The next section discusses how to integrate GitHub with IntelliJ.
